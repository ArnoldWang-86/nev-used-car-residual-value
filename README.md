## 一分钟看懂这个项目

**问题起点**：同样是开 3 年，蔚来 ES6 挂牌 16.99 万、Model Y 只挂 14.08 万——
**蔚来卖得更贵，保值率反而更低（50.3% vs 51.4%）**。差距里有多少是真实产品力，
多少只是「分母小所以比例好看」？

**做法**：

```
瓜子二手车公开详情页（robots.txt 明示 Allow: /car-detail/*.md）
        ↓ 合规采集器：? 参数硬断言 + 风控熔断 + 阶梯提速 + 断点续传
     746 条真实在售车源（新能源 726 条）
        ↓ 自建口径：残值率 = 挂牌价 ÷ 新车指导价，逐条校验
        ↓ 双因子 ANCOVA（Type II）+ 调整后边际均值（正确 CI 口径）
        ↓ 预测建模：精简 8 维特征 + LightGBM 原生类别车系
        ↓ 交付：可加载模型 + 命令行估价 + 单文件交互页面 + 一致性校验
```

**主要结论**：

- **车龄一个人解释保值率方差的 72%**，是最大单一解释变量；里程只贡献 −0.0035（消融实验）。
- 控制混淆变量后，**Model Y 保值率仍高于蔚来 ES6 达 6.2 个百分点**
  （4 年以上段扩大到 8.7pp，95% CI [+3.0, +9.5]）。
- **但该差距里约 4 个百分点来自分母效应**：只拉平新车标价时，优势从 +3.7pp **转为 −2.2pp**；
  而只拉平公里数时扩大到 +10.1pp（Model Y 里程比蔚来高 74%）。两项抵消后真实优势 +6.2pp。
- **蔚来 ES6 与 EC6 无显著差异**（+1.2pp，CI 跨 0）→ 可共用同一套残值曲线，无需分别建模。
- 折旧速度差异（交互项）**不显著**（p = 0.258）；当前样本量仅能检出 ≥5.9pp 的交互效应。

## 方法上值得说的四点

1. **两种交叉验证回答的不是同一个问题，不要混用。**
   随机 KFold R² **0.912**（考「认识的车系」，像日常给熟车估价）vs
   GroupKFold R² **0.779**（考「没见过的车系」，像新品牌刚进场）。
   早期版本曾把前者当「模型精度」宣传——那是**数据泄漏**，
   但两者都不是错的，只是问题不同。

2. **只用 8 个特征，精度反而比 90 维哑变量更高。**

   | 模型（GroupKFold by 车系） | MAE | R² |
   |---|---|---|
   | 常数基线（中位数） | 0.1575 | −0.179 |
   | Ridge 线性 | 0.0829 | 0.685 |
   | **交付版 LightGBM（8 维 + 原生类别车系）** | **0.0715** | **0.779** |
   | 原 90 维哑变量版 | 0.0786 | 0.717 |

   726 行配 55 车系 + 27 城市哑变量会让模型靠「背下车系」取胜；
   而车系哑变量在置换重要性上本来就只有 **2.4e-16**。换成原生类别特征后，
   模型对没见过的车系也能给出合理预测。

3. **预测区间是「单台车的预测区间」，不是均值置信区间。**
   用两个**分位数头**（α=0.05/0.95）直接回归区间边界，因此**允许非对称**
   （残值率分布左偏，对称的 ±1.96σ 会低估下方风险）。OOF 实测覆盖率 **89.8%**。

4. **「1 年后残值跌多少」给了两条轨，因为树模型不能外推时间趋势。**
   树模型是分段常数，在车龄区间边缘不会继续下降、会低估跌幅；
   本项目在公开数据集（17.6 万条）的时间外推实验里实测过：
   **树模型 R² 转负（−0.79 ~ −0.97），Ridge 反而 R² 0.338**。
   所以并列给出树模型轨与线性轨，**两轨差异本身就是「此处树模型是否可信」的信号**。
   现实锚点：控制车系／里程／指导价后，同一辆车一年约跌 **5.3 个百分点**。

## ⚠️ 已知局限（必须与结论一同阅读）

1. **单期快照**：746 条全部采集于 2026-10-12，模型**无法预测市场整体涨跌**；
   「1 年后残值」只反映车龄/里程自然衰减。
2. **挂牌价 ≠ 成交价**：预测的是**合理挂牌价**，系统性高于成交价，不能直接当收购价。
3. **存活偏差**：在售车源 = 还没卖掉的车，长期滞销车会拉高挂牌价。
4. **电池健康度未入模**：`soh_pct` 覆盖率 61.3%、`battery_kwh` 28.7%，
   且 SOH 全部来自平台文案抽取、**无实测依据**（审计发现 5 台车两处数字自相矛盾）。
   这是当前模型最大的已知信息缺口。
5. **样本量限制**：交互项（折旧速度差异）当前仅能检出 ≥5.9pp 的效应；
   核心对比只用 343/726 = 47% 样本（3 车系子集）。
6. **区间是全局标定的**：小样本车系（如 n=3 的品牌聚合档）的区间不会自动变宽；
   按车系做区间标定需要嵌套交叉验证，当前样本量支撑不了。
7. **不做因果推断**：所有差异均为相关性描述。

## 🔧 自我纠错记录

这个项目做了**三轮独立审计**，共发现并修正 **46 项问题**。挑三件最值得说的：

**① 稳健性检验从未真正执行过（P0）。**
脚本读取 `C(series)[T.Model Y]`，但 statsmodels 以 `蔚来ES6` 为参照水平，
取不到参数就**静默返回 nan**——五项检验全部输出 nan 却没有任何报错。
改用 `Treatment(reference=...)` 后重跑。**教训：不报错 ≠ 结果正确。**

**② 我在本 README 里写错过一个数字，并已更正。**
「把整个极氪品牌剔除后重训，该车系被低估 **7.26pp**」——这个数字与脚本输出不符。实测是：

| 口径 | 极氪7X 平均预测 | 偏差 |
|---|---|---|
| 实际平均残值率（n=22） | 75.73% | — |
| 用「见过极氪7X」的模型（OOF） | 66.27% | −9.46pp |
| 把极氪品牌整体剔除后重训 | 67.34% | −8.39pp |
| **退化幅度** | | **−1.07pp** |

**退化只有 1.07pp，没有想象中大**——因为未知档不是「空白模型」，
它仍能用**车龄／里程／指导价**给出预测，再加上同品牌其他车系充当代理。
**真正的问题不是「退化多少」，而是「偏差本来就大」**：极氪7X 是 2025 年新上牌的车，
残值率高达 75.7%，两种模型都系统性低估它 8~9 个点。
**教训：文档里的每个数字都必须是脚本输出，不能凭印象写。**

**③ 补预测能力时查出 6 处「不报错但结果全错」的静默失效。** 举两个典型：

- 特征工程函数 `build_features()` 内部按**全表样本量**判断是否并档。
  推理单辆车时该行样本量恒为 1 → **任何车系都被并成「未知档」**，
  训练时说的「ES6 独立建模」在推理侧永远不生效。用 CLI 估一辆 ES6 才发现
  （输出显示命中「未知车系」，与模型卡的 122 条样本矛盾）。
- 导出给前端页面的模型 `features` 字段**漏了类别特征 `series_cat`**，
  页面算不出类别下标，`vec[undefined]` 把车系编码写成了数组外属性 →
  **所有车系静默退化成「未知档」**。是校验脚本里
  「同一车系档内不同车辆必须有不同预测」这条断言抓出来的（极差为 0）。

**这轮经验已固化成两道防线：**

| 防线 | 作用 |
|---|---|
| `src/20_verify_page.py` | 从**实际生成的 HTML** 里抽 JS，在 Node 下跑 120 辆真实车辆与 Python 逐点比对（点估计与区间均 **0 误差**），并断言车系编码确实生效 |
| `src/21_shot_page.py` | 无头浏览器真实渲染 + 抓 console 错误 + 交互与边界验证 + 截图留档（曾靠它抓到「车龄 96 月时下标越界导致白屏」） |

## 数据来源与合规声明

数据来自**瓜子二手车公开详情页**，采集依据是该站 `robots.txt` 的明示放行：

```
GET https://www.guazi.com/robots.txt
  User-agent: *
  Allow: /                      ← 通用爬虫明确放行
  Allow: /car-detail/*.md       ← 官方为 AI 场景开放的详情 Markdown
  Disallow: /*?*                ← 仅禁带查询参数的 URL
```

- 采集器内置 `assert_path_only()` **硬断言**：任何含 `?` 的 URL 直接抛异常。
- 仓库**不转载原始挂牌数据**（`data/raw/`、`data/clean/` 已在 `.gitignore` 中排除），
  仅保留 5 条样本用于说明字段口径。完整数据请自行运行采集脚本获取。
- 本项目为**个人求职作品集**，仅用于方法学习与研究，不做商业用途。
- 公开数据集 `imbalet/used_cars`（俄罗斯二手车挂牌，17.6 万条）用于方法学验证，
  其折旧**趋势**可借鉴，**绝对水平不可套用到中国或新能源车**。
