## 二、目标变量

| 字段 | 类型 | 单位 | 说明 |
|---|---|---|---|
| `full_payment` | float | 元 | 平台挂牌价（一次性全款） |
| `guide_price` | float | 元 | 新车指导价 |
| `residual_rate` | float | 比例 | **本项目的回归目标** = `full_payment / guide_price` |

### ⚠️ 目标变量陷阱（必须写进 README 与面试表述）

1. **`full_payment` 是挂牌价，不是成交价。** 本项目预测的是"挂牌残值率"，
   与"成交残值率"存在系统性差异（挂牌通常会留有议价空间）。
2. **`guide_price` 的口径可能混合。** 实测未验证它是"上市时指导价"还是"当前在售款指导价"。
   对蔚来这类有选装、有 BaaS 车电分离的车型，分子分母都会受影响。
3. **BaaS / 换电车型的残值口径根本不同。** 电池租赁的车，二手价不含电池，
   用同一套 `full_payment / guide_price` 会低估其真实保值水平。
   **必须用 `is_battery_swap` 标记并分层分析。**

## 五、能源与三电（本项目的差异化维度）

| 字段 | 类型 | 示例 | 说明 |
|---|---|---|---|
| `energy_type` | str | `新能源` / `燃油车` | 能源类型 |
| `engine` | str | `0.0L` | 排量（新能源为 `0.0L`） |
| `battery_kwh` | float | `100.0` | **电池容量**，从 `model` 正则抽取 |
| `v_battery_kwh` | float | `75.0` | `highlights` 中文描述里的容量（`75度电池`），交叉校验用 |
| `soh_pct` | float \| NaN | `87.0` | **电池健康度 SOH**，从 `highlights` 抽取 |
| `battery_chem` | str \| NaN | `三元锂` / `磷酸铁锂` | 电池化学体系，从 `highlights` 抽取 |
| `cltc_km` | float \| NaN | `635` | CLTC 续航，从 `highlights` 抽取 |
| `is_battery_swap` | bool | `True` | 是否换电/BaaS 车型（关键词：`换电`） |
| `battery_note` | str | `换电更换件` | 电池相关的原文片段，保留可追溯性 |

### ⚠️ SOH 字段的诚实说明

`soh_pct` **不是每个车源都有**——它只出现在瓜子生成的 `highlights` 描述文本里。
必须统计并公开其**覆盖率**，覆盖率不足时：

- **不得**用该字段直接训练模型后宣称"模型用到了电池健康度"
- 正确做法：把有 SOH 的子集单独作为**验证锚点**（检验容量分桶是否合理），
  或作为**敏感性分析**的一维，而非主模型特征

## 六、车况评估

| 字段 | 类型 | 示例 | 说明 |
|---|---|---|---|
| `appearance_score` | int | `90` | 成色分（满分 100） |
| `condition_grade` | str | `A` | 车况等级 `S/A/B/C/D` |
| `condition_desc` | str | `基础车况达标/理赔1次/过户0次` | 车况描述原文 |
| `claim_times` | int | `1` | 理赔次数，从 `condition_desc` 抽取 |
| `has_structural_repair` | bool | `False` | **结构件修复**（纵梁/骨架切割焊接），残值重大负面信号 |

### 车况等级口径（站点公示，摘自详情页）

- **基础车况极品**：0 理赔，过户 ≤ 1 次
- **基础车况优秀及以上**：理赔总额 / 新车价 ≤ 3%，过户 ≤ 3 次
- **基础车况良好及以上**：理赔总额 / 新车价 ≤ 8%，过户 ≤ 5 次
- **基础车况达标及以上**：理赔总额 / 新车价 > 8%，或过户 > 5 次

> 注意：`condition_grade`（S/A/B/C/D）与"基础车况×级"是**两套体系**，不要混用。

## 九、数据源本身的结构性局限（必须写进 README）

1. **只有当前快照，历史价格不可回溯。** 面板必须从今天起靠**周度快照**自行积累。
2. **时间切片偏误。** 所有样本同一日期采集，无法直接观测市场时间趋势，
   建模时须按 `first_register` 年份做**时间外推验证**，否则会把"市场在跌"
   误当成"老车不值钱"。
3. **规模上限受合规约束。** 因 `Disallow: /*?*`，每个列表页仅 40 条，
   无法按 `?page=` 翻页，总量在千级而非豆包报告估计的万级。
4. **`highlights` 是平台生成的自然语言**，抽取出的 SOH / 化学体系 / 续航
   属于**非结构化转结构化**，需人工抽检核对，准确率要如实报告。
